## Decisions
- Мутационные прогоны crypto запускаются узко (`--lib --test data`): полный список из 71 мутаций идёт около часа; числа в документах брать только из прогона на финальном коде (первые числа были до рефакторинга и отличались).
- Пределы стоимости Argon2id/scrypt/PBKDF2 вынесены в чистые функции с модульными тестами на каждую границу, чтобы тесты не хешировали гигабайты в отладочной сборке; две мутации scrypt (граница стоимости) эквивалентны проверке памяти и убраны, две мутации Argon2id (ноль проходов, хеш 3 байта) эквивалентны проверке самой библиотеки.
- Исправление зависания `sqlite.close` вынесено в отдельный коммит от `crypto`; тест теперь ждёт заполнения окна кредита (1,5 с) и без исправления падает всегда.
- Миграцию данных Fjall старого File Manager не делать (одна настройка языка, другой путь данных); старую папку не трогать; сказать пользователю при итоговом отчёте.
- Новый код ошибки `NETWORK` (502) для сбоев сети вместо перегрузки существующих кодов; подмена права `net.http` — запрос висит до таймаута (30 с по умолчанию) и падает `TIMEOUT`, как мёртвая сеть по плану §6.4; куки (`cookieJar`) в `http` не реализованы — записать как отклонение в итогах M4.
