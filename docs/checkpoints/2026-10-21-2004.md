## Decisions
- гейт лицензий по ключу кэша с записью только после зелёной проверки, а не по сравнению `before`/`after` пуша: красная проверка не замолкает на следующем пуше; слабое место: запись живёт 7 дней без чтений и не видна из других веток (проверка тогда просто повторится).
- один список разрешённых лицензий (`deny.toml`) для Rust и npm и собственный скрипт вместо новой npm-зависимости.
- runtime собран в CI (release dry-run, профиль `dist`, без тестовых хуков), а не локально; отвергнут debug-артефакт обычного CI (с e2e-хуками и ANGLE DLL).
- тексты `LICENSE-*` в staging берутся из корня исходников (как в платформенных пакетах), а не дублируются в каждом пакете.
- память runtime: владелец решил ничего не менять; кандидаты (пулы потоков Servo, `js_mem_*`, `network_http_cache_size`, fjall cache) не принимались и не записаны задачами.
