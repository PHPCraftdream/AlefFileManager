## Decisions
- Запуск пакета: `alef run <путь>` и `--app <путь>` — один конвейер; подписанный пакет — trust on first use ключа по точному `id`, неподписанный только после предупреждения или `--allow-unsigned`, неподписанный после подписанного отказ; consent, данные, секреты и single-instance ключуются токеном authority (SHA-256 с доменным префиксом `v1`), регистрации автозапуска и deep links для пакета отказывают; `$APP` и `sidecar:` для архива недоступны; лимиты запуска 256 МиБ архив, 64 МиБ ассет, четыре одновременных запроса.
- Грамматика поля `runtime` — ровно `semver::VersionReq` (Cargo), без своего разбора; версия пакета — строгий SemVer только для пакетов.
- `assets` по умолчанию `dist`, без отката на корень; избыточные проверки удаляются, когда мутация выжила.
- Платформенные npm-пакеты runtime не коммитятся каталогами (лимит 7 элементов), а генерируются скриптом из таблицы платформ, закреплённой тестом против матрицы CI.
- Шаг-эксперимент Windows без GPU удалён; продуктовое ограничение (Windows без аппаратного OpenGL) вынесено в #117.
