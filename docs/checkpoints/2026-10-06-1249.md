## Decisions

- Сессия = документ: `runtime.hello` сам создаёт/заменяет сессию окна по `Request.pipeline_id` (новый pipeline на каждую загрузку, включая reload; устаревший документ получает 403); `LoadStatus::Started` сессиями не управляет — отвергнуто: создание по `Started` (для первой загрузки его нет, а для остальных он может прийти позже скрипта страницы).
- `alef` отказывается от манифестов, которые рантайм пока не умеет выполнять (процентные размеры окна, несколько окон, `monitor`/`position`/`restore` не по умолчанию — до модуля окон M2.2), код выхода 2 и сообщение с кодом ошибки — отвергнуто: молча урезать манифест.
- CSP из манифеста: `'self'` не совпадает с непрозрачным origin `native://app` в Servo, поэтому `build_csp(.., "native://app")` явно добавляет этот источник во все load-директивы; заголовок `Origin` для собственных схем Servo не добавляет, мост подставляет origin документа (`request.origin`; для `native://` — `null`).
- Работа идёт на ветке `alef-m1` (не на `main`), push только в неё и без force; коммит нужен для CI — отвергнуто: трогать `main` без просьбы.
- CI: sccache опционален (фолбэк на обычный rustc, если кэш Actions недоступен) — отвергнуто: считать сбой сервиса кэша падением сборки.
