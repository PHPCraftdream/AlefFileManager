## Decisions
- cli на Windows: PATHEXT пробуются раньше имени без расширения; `resume()` будит все приостановленные потоки ребёнка.
- Ограничение Unix записано в документацию: потомок, сам сделавший `setsid`, уходит из группы процессов; на Windows Job Object без breakaway держит и таких.

- Объявленные команды: право `cli.command:<name>`, `cli.run`/`cli.start`, шаблон `{param}` — только целый элемент; `sidecar:<name>` = `$APP/bin/<name>`, не по PATH.
- Отвергнуто: оставлять `detached` для внуков на всех ОС (на Unix это обходит групповой kill).
