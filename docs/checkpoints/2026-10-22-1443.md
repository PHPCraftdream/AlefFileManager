## Decisions
- вариант 1 по профилю Servo (профиль на приложение, Servo строится при запуске), а не общий профиль: общий профиль небезопасен (куки/пароли HTTP Basic/HSTS пишутся только на выходе процесса, кэш по URL, очистка по origin неполна), и главную метрику «сигнал → ALEF_READY» он не улучшает; патчи Servo исключены.
- прогрев включается галочкой в установщике и управляется и останавливается через CLI; оба уровня сразу, но окно и GL без Servo — только если замер превысит порог (≥~100 мс или ≥15% до первого кадра).
- реестр npm читается напрямую через `fetch`, а не через `npm pack` (нет проблемы с `npm.cmd`, integrity проверяется самим инструментом).
- новое приложение File Manager — отдельный публичный репозиторий без истории; переименование репозитория выполнено мной по явному выбору владельца.
- после слияния ветки сливаются `--no-ff` только после зелёного CI; агентам запрещены сборки и тесты, проверка в GitHub CI.
