## Decisions
- Формат пакета `.alef`: имена только ASCII (`A-Za-z0-9._-@+` и `/`), без директорий, ZIP64, data descriptors и extra-полей; читатель строгий (`verify_strict`), JS-проверка мягче и не нормативна; общий набор из 86 векторов проверяет оба читателя.
- Крейт `alef-package` разбирает контейнер сам (без крейта `zip`), только `flate2` для deflate; избыточные проверки удалены, когда мутация выжила (CR/BOM в списке хешей, повторное base64).
- `assets` по умолчанию `dist` без отката на корень приложения (рекомендация ревьюера; цена: миграция всех e2e-фикстур и File Manager).
- Полный Windows e2e на программном контексте идёт как шаг-эксперимент (`continue-on-error`), обязательным остаётся шаг с восемью сценариями без окна.
- Агентские результаты без отчёта и с избыточной сложностью переношу в свежий worktree и упрощаю; патч в основной checkout делаю против HEAD worktree, не против baseline, если в baseline попали мои файлы.
