## Decisions
- cli: `permissions.cli.exec` — программа резолвится по PATH рантайма и запускается по абсолютному пути; `PATH/PATHEXT/COMSPEC/LD_*/DYLD_*` из `env` страницы запрещены (кроме `*`); оболочка с операторами только при `*`; подмена = «мёртвая программа» (висит до timeout → TIMEOUT).
- Консольный режим: `windows: []` + `console: true`, документ — `entry` (по умолчанию `/`); сигналы спрашивают документы как `app.quit`, второй сигнал завершает сразу; вывод страницы ждёт `Console::drain` (до 5 с) перед выходом; Windows без GL — явная ошибка и пропуск e2e, а не скрытый обходной путь.
- WebSocket-сервер: обёртка JS разложена слоями без кольца импортов (`body` → `websocket-connection` → `http-server` → `http` → `websocket`), сервер HTTP вынесен в `net/http/server/` (лимит записей в каталоге).
- Отвергнуто: оставить тест предела синхронным (виснет на Linux/macOS); писать e2e-сценарий консоли в новый файл (каталог `tests/e2e/scenarios` полон, поэтому в `modules.mjs`).
