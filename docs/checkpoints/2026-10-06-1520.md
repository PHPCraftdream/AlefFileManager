## Decisions

- Скрытый старт окна + показ по первому непустому кадру (с запасными сроками) вместо показа по `LoadStatus::Complete` — отвергнуто: после `Complete` первый кадр белый (React монтируется позже); также отвергнуто: заливать фон окна цветом (маскировка, а не исправление).
- Мелькающее окно `surfman` убрано локальной копией крейта `backend/patches/surfman` (как `servo-paint`, `winit`) — отвергнуто: перехват создания окна через CBT-hook (хрупко) и предсоздание класса окна (паника `assert_ne!` в surfman).
- Аргументы приложения у универсального запуска идут после `--` (`alef --app dir -- --port 80`), раздел `arguments` манифеста необязателен, разборщик свой без зависимостей — отвергнуто: `clap`/`lexopt` (лишняя зависимость ради двух форм записи).
- Модули подключаются через `BridgeOptions.modules` (инсталлятор получает реестр и `Host`), `alef-runtime` модулей не знает — отвергнуто: зависимость `alef-runtime → alef-modules`.
- Работа на ветке `alef-m1`, push только в неё и без force (разрешение пользователя «если нужно — делай пуш»); коммиты нужны для CI — отвергнуто: трогать `main`.
