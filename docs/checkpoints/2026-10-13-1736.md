## Decisions
- Прогоны сегментируются: пуш в ветку задачи = только затронутое на Linux; полный прогон на четырёх ОС — `main`, ночной schedule, `[full]`, ручной `full=true`; неизвестные пути расширяют план, никогда не сужают; после каждого пропущенного ОС-специфичного падения путь добавляется в `scripts/ci/affected.json`.
- Умолчание продукта на Windows остаётся WGL; ANGLE включается только в CI (фича `angle`); решение сделать его умолчанием — за пользователем.
- Хранилище секретов Linux-раннера не живёт между процессами: проверка «секрет выжил» в e2e пакета даёт SKIP, если пропала и канарейка; падение только при выжившей канарейке.
- Очередь ассетов архива: 4 одновременных чтения + 256 ожидающих, сверх — 429 (вместо отказа пятому).
- Агентам с конфликтом структуры (лимит 7 записей) переносим файлы, не исключаем лимит (`permissions.rs` → `consent/permissions.rs`, `dev/start` → `scripts/app/`).
