## Decisions
- ConPTY: конец вывода — закрытие канала (`BROKEN_PIPE`), а не флаг после `ClosePseudoConsole`; флаг оставлен только как предел в 5 с (отверг: пауза перед `Close` — гадание без доказательства; документация Microsoft прямо велит читать до закрытия канала).
- R-013: слот вызова держит транспорт до готового ответа (контекст его только заимствует); `UNCOUNTED` — `runtime.stream.ack/close/end` (отверг: исключать все `runtime.*` — `write` ждёт читателя; таймаут `websocket.send` не делал: обрыв посреди кадра ломает поток, зависшая отправка теперь занимает бюджет ожидающих, а не бегущих).
- R-001/R-002: из условия уборки убрал `Arc::strong_count` (избыточно рядом с `is_terminal`), вместо этого тест на «живой входящий поток остаётся» и на порог уборки.
- Перезапуск приложения (`start_again`) выходит из job/группы оконного ребёнка (breakaway на Windows с откатом, `process_group(0)` на Unix) — иначе замену убивала защита лаунчера.
- Харнес мутаций `.rush/m3-mutate.mjs` теперь завершается с кодом 2 при пустом фильтре (прежнее «all mutations caught» при пустом фильтре было ложным).
